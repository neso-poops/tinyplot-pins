# tinyplot-pins

Public image host for [The Tiny Plot](https://pinterest.com/thetinyplot), a Pinterest account about
growing vegetables in small spaces — balconies, windowsills and containers.

Pinterest's bulk Pin upload needs a publicly reachable direct URL for every image, so the pin
graphics are served from here through GitHub Pages. That is all this repository is: static image
hosting. Nothing here is code.

Images are served from `https://neso-poops.github.io/tinyplot-pins/<filename>.jpg`.
